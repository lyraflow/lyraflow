# Third-party components

The files in this directory were generated by the shadcn/ui CLI and are
vendored source rather than a dependency — we own and modify them, and they
do not update on their own.

- shadcn/ui — MIT. https://ui.shadcn.com
- Radix UI primitives (runtime dependency) — MIT. https://www.radix-ui.com
- Lucide icons (runtime dependency) — ISC. https://lucide.dev

All three are permissive and compatible with this repository's licence.
Their copyright notices are retained in the source and in the dependency
packages' own LICENSE files.

These files are excluded from this repository's Biome configuration: they do
not match its house style and should not be reformatted to.
